About This Project

JPMC Loan Grader

An end-to-end machine learning system built for JPMorgan Chase & Co. to predict customer loan grades (A–F) using historical banking, credit card, and loan transaction data. Replaces manual credit assessment with a 95.4% accurate Random Forest model deployed as ONNX in the browser — no server required.

Methodology

End-to-End ML Pipeline

1
Data Collection
5,000 customer records across banking, card, and loan history. 26 features, 3% missing values injected realistically.
2
EDA
Distribution analysis, correlation heatmap, outlier detection (IQR), missing value profiling, grade-wise breakdowns.
3
Preprocessing
Median imputation, StandardScaler, LabelEncoder for categoricals. 80/20 stratified train-test split.
4
Training
8 algorithms benchmarked. 5-Fold Stratified CV. RandomForest selected (95.4% acc, 0.728 AUC).
5
Export
skl2onnx converts the trained RF to ONNX format. Meta.json exports all preprocessing stats for JS replication.
6
Browser Inference
onnxruntime-web runs the model via WebAssembly. Preprocessing in JS. Zero server dependency.

FAQ
Frequently Asked Questions
Is this using the real trained model?
Yes. The predictor loads loan_grader.onnx — the actual RandomForestClassifier trained in the Jupyter notebook, exported via skl2onnx. It runs entirely in your browser using WebAssembly via onnxruntime-web. No fake heuristics.
Why does the predictor need a local server?
Browsers enforce CORS restrictions on file:// URLs and block fetching binary files (.onnx) and JSON directly. Running python serve.py starts a local HTTP server at http://localhost:8080 that bypasses this restriction.
How is preprocessing handled in the browser?
loan_grader_meta.json contains the fitted imputer medians, scaler mean/std, and label encoder classes from the notebook. The JavaScript in predictor.js applies the exact same transformations before passing the feature vector to the ONNX model.
What does the loan grade mean?
Grades A–F represent a 6-tier credit risk classification based on predicted credit score (300–900). Grade A (800–900) = lowest risk / best rates. Grade F (300–399) = highest risk / decline recommended. The model outputs a probability for each grade, not just a hard label.
How accurate is the model?
The Random Forest achieves 95.4% accuracy on the held-out test set (1,000 records) and 0.728 macro ROC-AUC. It was selected as the best among 8 algorithms evaluated. Note: the dataset is synthetically generated for demonstration; real JPMC production data would yield different metrics.
How do I retrain the model?
Run models/train_and_export_onnx.py — it retrains the Random Forest on the latest data, evaluates it, saves an updated .pkl, exports loan_grader.onnx, and regenerates loan_grader_meta.json. Then copy both files to website/assets/.
